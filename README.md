# DA - Digital Archive

DA files your photos and scanned documents by the date they were taken: it sets exact
duplicates aside, renames each file by its date, and puts it in a `YYYY\YYYY-MM` folder.
It never deletes anything, and it asks before it moves anything.

- **User guide:** https://da.gamenightbymike.com
- **Download (Windows):** [DA.exe, latest version](https://github.com/devmukmuk/DA/releases/latest/download/DA.exe)

This repository holds the latest release and the user guide's web pages. It is updated
automatically each time a new version of DA is published.
